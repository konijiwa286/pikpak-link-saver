# 使用指南

[返回项目首页](../README.md)

## 账户连接

首次点击“连接 PikPak”，在官方授权页确认设备码。有效授权保存在私人目录，后续启动自动恢复。网络异常会自动重试；“重试连接”先检查现有授权，不重复申请设备码。

单账号任务会核对账户身份。更换账户后，原有任务的远端操作会暂停，恢复原账户后继续。

## 添加与查看任务

设置目标根目录，粘贴一个或多个公开链接。支持 Markdown 列表、`&amp;` 和 `\&`，保留搜索查询参数。默认在粘贴后自动开始，也可关闭开关后手动提交。

按合集、批次和“需处理”查看进度。列表先显示 100 项，可继续加载；搜索匹配当前视图的完整列表。“最近文件”是最近 100 项窗口，历史失败和待核对项仍在“需处理”中。

“重试失败项”只重试明确失败的文件。提交结果不明时继续核对远端，避免重复保存；解析不完整的批次可以重新解析。

## 网络与本机中转

可在“网络设置”填写不含账号密码的 HTTP(S) 代理，例如 `http://127.0.0.1:7890`。留空时继承启动环境的代理；更改后供后续请求使用。

可启用“云下载失败时允许本机中转”。该模式使用本机网络和磁盘续传下载、上传，远端核对成功后清理临时副本。有效断点保留用于恢复。

## 退出与恢复

```sh
./启动.sh --no-browser   # 只打印页面地址
./启动.sh --stop         # 结束当前用户后台
python3 main.py --serve  # 在前台运行
```

关闭最后一个程序页面后，后台约 3 秒后开始退出。刷新有缓冲，多页面不会互相误关；浏览器异常退出时通过心跳超时回收。未打开任何程序页面时约一分钟后退出。

已提交给 PikPak 的云下载可能继续在云端执行。重新启动后恢复本机记录，并核对远端状态。

## 数据与环境变量

默认数据目录为 `${XDG_DATA_HOME:-~/.local/share}/pikpak-link-saver`。授权目录权限为 `0700`，数据库和实例描述文件为 `0600`。

| 变量 | 用途 |
| --- | --- |
| `PIKPAK_CLI` | 官方 CLI 可执行文件路径；默认先查找项目中的 `bin/pikpak`，再查找 `PATH`。 |
| `PIKPAK_SAVER_HOME` | 本程序的私人数据目录。 |
| `PIKPAK_DIR` | CLI 授权目录，默认使用私人数据目录下的 `auth`。有效目录会记录下来供后续启动沿用。 |

服务仅监听 `127.0.0.1` 随机端口，写请求校验 Host、Origin 和本机 Token。授权和任务资料与源码分开存放，不进入仓库。

## 资源限制

统计在 SQLite 中聚合，待核对项目按块读取。页面隐藏时只发送轻量心跳，返回后同步进度。本机下载进度约每秒写入数据库。

单次来源 HTML / JSON 元数据响应上限为 16 MiB，搜索上限为 10,000 页。超限会明确报错，可缩小来源范围；媒体文件下载不受这个元数据上限限制。
